# Keyboard shortcuts

<!-- Generated from the sprite packer's key bindings by `vp run docs`. Edit the labels in its keys.ts, not this file. -->

Ctrl means Cmd on macOS. Letter keys work while the canvas or a panel has the focus, not while you type in a field; Save, Save as, Open and Export work everywhere.

### History and files

| Keys | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as file |
| Ctrl+O | New or open (start screen) |
| Ctrl+E | Export the way the Export button shows |

### Sprites

| Keys | Action |
| --- | --- |
| Delete | Remove the selected sprites |
| Esc | Deselect |
| F2 | Rename the selected sprite (in the list) |
| ↑, ↓ | Previous or next sprite (in the list) |
| Ctrl+A | Select all sprites (in the list) |

### View

| Keys | Action |
| --- | --- |
| F | Fit to view |

### Canvas

| Keys | Action |
| --- | --- |
| Middle-drag, Space+Drag | Pan |
| Wheel | Zoom at the pointer |
| Shift+Wheel | Pan sideways |
