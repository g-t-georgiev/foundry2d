# Keyboard shortcuts

<!-- Generated from the level designer's key bindings by `vp run docs`. Edit the labels in its keys.ts, not this file. -->

Ctrl means Cmd on macOS. Letter keys work while the canvas or a panel has the focus, not while you type in a field; Save, Save as, Open and Export work everywhere.

### History and files

| Keys | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as file |
| Ctrl+O | New or open (start screen) |
| Ctrl+E | Export in the format the Export button shows |
| Ctrl+Shift+C | Copy the active layer as an array |

### Painting (level view)

| Keys | Action |
| --- | --- |
| B | Pen |
| E | Eraser (or paint with the right mouse button) |
| R | Rectangle fill |
| G | Bucket fill |
| I | Pick value or tile |
| Hold Alt | Pick value or tile while held |
| X | Flip painted tiles horizontally |
| Y | Flip painted tiles vertically |
| 1–9 | Choose the IntGrid value, or the entity type to place |

### View

| Keys | Action |
| --- | --- |
| F | Fit to view |
| # | Grid on/off |
| +, = | Zoom in |
| - | Zoom out |

### Entities (on an Entities layer)

| Keys | Action |
| --- | --- |
| Delete, Backspace | Delete the selected entity |
| Ctrl+D | Duplicate the selected entity |
| ←, →, ↑, ↓ | Nudge the selected entity by a cell |
| Shift+←, Shift+→, Shift+↑, Shift+↓ | Nudge the selected entity by a pixel |
| Esc | Cancel picking, then deselect |

### World and levels

| Keys | Action |
| --- | --- |
| Esc | Back to the world view |
| Enter | Open the selected level |
| Delete | Delete the selected level (world view) |
| Ctrl+D | Duplicate the selected level (world view) |
| F2 | Rename the selected level (in the Levels list) |

### Canvas

| Keys | Action |
| --- | --- |
| Middle-drag, Space+Drag | Pan |
| Wheel | Zoom at the pointer |
| Shift+Wheel | Pan sideways |
