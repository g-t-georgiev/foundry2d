# Keyboard shortcuts

<!-- Generated from the pixel editor's key bindings by `vp run docs`. Edit the labels in its keys.ts, not this file. -->

Ctrl means Cmd on macOS. Letter keys work while the canvas or a panel has the focus, not while you type in a field; Save, Save as, Open and Export work everywhere.

### History and files

| Keys | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as file |
| Ctrl+O | New or open (start screen) |
| Ctrl+E | Export… |

### Tools

| Keys | Action |
| --- | --- |
| B, P | Pen |
| E | Eraser |
| G | Paint bucket |
| I | Colour picker |
| L | Line |
| R | Rectangle (Shift: filled) |
| C | Ellipse (Shift: filled) |
| M | Select and move |
| Q | Lasso select |
| W | Magic wand |
| [ | Smaller pen |
| ] | Bigger pen |
| Hold Alt | Colour picker while held (not with a selection tool) |

### Selection and clipboard

| Keys | Action |
| --- | --- |
| Ctrl+A | Select all |
| Ctrl+D, Esc | Deselect |
| Ctrl+C | Copy (also as an image for other apps) |
| Ctrl+X | Cut |
| Ctrl+V | Paste (also images from other apps) |
| Delete | Clear the selection, or the whole layer |
| Shift+H | Flip horizontally (selection or layer) |
| Shift+V | Flip vertically (selection or layer) |
| Shift+R | Rotate 90° clockwise (selection or layer) |

### View

| Keys | Action |
| --- | --- |
| Shift+X | Mirror drawing left/right |
| Shift+Y | Mirror drawing top/bottom |
| # | Grid on/off |
| Alt+P | Preview mode on/off |
| Alt+O | Onion skin on/off |
| F | Fit to view |
| +, = | Zoom in |
| - | Zoom out |

### Layers and frames

| Keys | Action |
| --- | --- |
| N | New layer |
| , | Previous frame |
| . | Next frame |
| Shift+N | New frame |
| Shift+D | Duplicate frame |

### Canvas

| Keys | Action |
| --- | --- |
| Middle-drag, Space+Drag | Pan |
| Wheel | Zoom at the pointer |
| Shift+Wheel | Pan sideways |
